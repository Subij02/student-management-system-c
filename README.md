# Student Management System (C)

A console-based Student Management System written in C using Xcode.

## Features

- ✅ Add Student
- ✅ View Students
- ✅ Search Student
- ✅ Delete Student
- ✅ Save Students to File
- ✅ Load Students from File
- Modular programming (.c/.h)

## Technologies Used

- C
- Xcode
- Git
- GitHub

## Concepts Practiced

- Structures
- Arrays
- Functions
- Loops
- File Handling
- CRUD Operations
